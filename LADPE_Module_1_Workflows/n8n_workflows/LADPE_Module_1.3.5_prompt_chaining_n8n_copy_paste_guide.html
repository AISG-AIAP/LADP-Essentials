Prompt Chaining in n8n

Copy-paste reference for the Research Agent to Analyst Agent to Report Writing Agent demo. Click Copy on any block and paste it straight into n8n.

Follow along with the video. Every prompt, expression, and JSON schema used in the demo is on this page, so you never have to type or memorise anything.

Chat Trigger → Research Agent → Analyst Agent → Report Writing Agent

Before You Start: The One Thing That Trips Everyone Up

Every node in the chain gets its input from the node before it, and in n8n you wire that up with an expression rather than plain text. There are only two expressions to learn for this demo.

1. The topic expressionFirst agent only - reads what the learner typed in the chat window 
{{ $json.chatInput }}
2. The chaining expressionEvery agent after the first - passes the previous agent's structured output along 
{{ JSON.stringify($json.output, null, 2) }}
Switch the field to Expression first. In the Prompt (User Message) field, hover over it and choose Expression instead of Fixed. If the field stays on Fixed, n8n sends the literal text {{ JSON.stringify($json.output, null, 2) }} to the model instead of the research data. When it is set correctly, the Result preview under the field shows the actual JSON from the previous node.

What the expressions are doing

Part Meaning
{{ ... }} Tells n8n to run JavaScript instead of treating the text literally.
$json The data coming out of the node immediately before this one.
.chatInput The field a Chat Trigger node puts the user's typed message into. Only available when the chat trigger is the node feeding in.
.output The field an AI Agent node writes its answer into. With a Structured Output Parser attached, this is a real object, not a string.
JSON.stringify(..., null, 2) Turns that object back into readable, indented JSON text so the next model can read it cleanly.

Step 1: Research Agent

  1. Start with a Chat Trigger node (When chat message received). This is where the topic comes from.
  2. Add an AI Agent node, rename it to Research Agent (the name matters for Step 3), and connect the trigger into it.
  3. Connect a Chat Model to it.
  4. Set Source for Prompt (User Message) to Define below, switch the field to Expression, and paste the expression below.
  5. Turn on Require Specific Output Format and attach a Structured Output Parser.
  6. In the parser, set the schema type to JSON Schema and paste the schema below.
System Message 
You are a research specialist. Your job is to search for credible information about the given topic and compile key findings.

For the topic provided, search for:
1. Recent developments or news
2. Key statistics and data
3. Expert opinions or authoritative sources
4. Important facts
Prompt (User Message)Expression mode - takes the topic the learner types in the chat window 
{{ $json.chatInput }}

The topic is not hardcoded. chatInput is the field the Chat Trigger node produces, so whatever you type in the chat window becomes the research topic. If you would rather wrap the topic in an instruction, use this version instead:

Prompt (User Message) - instruction variant 
Research this topic thoroughly: {{ $json.chatInput }}
In the chat window, type the topic you want researched, for example autonomous vehicles. If Source for Prompt (User Message) is left as Connected Chat Trigger Node, n8n already passes chatInput for you and you do not need an expression at all. Set it to Define below when you want to control the wording, as in the variant above.
Structured Output Parser - JSON Schema 
{
  "type": "object",
  "properties": {
    "topic": {
      "type": "string",
      "description": "Topic of the research or discussion"
    },
    "key_findings": {
      "type": "array",
      "items": { "type": "string" },
      "description": "List of key findings from the research"
    },
    "sources": {
      "type": "array",
      "items": { "type": "string" },
      "description": "List of sources referenced"
    },
    "statistics": {
      "type": "array",
      "items": { "type": "string" },
      "description": "List of relevant statistics"
    },
    "number_of_sources": {
      "type": "number",
      "description": "Number of sources found"
    },
    "is_statistics_available": {
      "type": "boolean",
      "description": "Is there any statistics available for this topic"
    }
  },
  "required": [
    "topic",
    "key_findings",
    "sources",
    "statistics",
    "number_of_sources",
    "is_statistics_available"
  ]
}
Test this agent before building the rest. Open the chat panel, send your topic, and check the Output panel for an output object containing topic, key_findings, sources, and statistics. Steps 2 and 3 only work once this one does.

Step 2: Analyst Agent

  1. Add a second AI Agent node named Analyst Agent and connect the Research Agent into it.
  2. Set Source for Prompt (User Message) to Define below.
  3. Switch the Prompt (User Message) field from Fixed to Expression, then paste the expression below.
  4. Attach a Structured Output Parser with the analysis schema.
Prompt (User Message)Expression mode - this is the chaining step 
{{ JSON.stringify($json.output, null, 2) }}
System Message 
You are a data analyst. Review the research findings and:

1. Identify the most important insights
2. Spot trends or patterns
3. Determine what's most relevant for a business audience
4. Rate the credibility of information

Focus your analysis on business implications.
Structured Output Parser - JSON Schema 
{
  "type": "object",
  "properties": {
    "main_insights": {
      "type": "array",
      "items": { "type": "string" },
      "description": "List of the main insights drawn from the research"
    },
    "trends": {
      "type": "array",
      "items": { "type": "string" },
      "description": "List of trends identified in the research"
    },
    "credibility_rating": {
      "type": "string",
      "enum": ["high", "medium", "low"],
      "description": "Credibility rating of the research: high, medium or low"
    },
    "recommended_focus": {
      "type": "string",
      "description": "What to emphasize in the report"
    }
  },
  "required": [
    "main_insights",
    "trends",
    "credibility_rating",
    "recommended_focus"
  ]
}

Optional: label the research data for the model

If you prefer to give the model a little context instead of a bare JSON blob, use this version in the same Expression field.

Prompt (User Message) - labelled variant 
Analyze these research findings:

Research Data:
{{ JSON.stringify($json.output, null, 2) }}

Provide your analysis focusing on business implications.

Step 3: Report Writing Agent

  1. Add a third AI Agent node named Report Writing Agent and connect the Analyst Agent into it.
  2. This agent needs both earlier outputs, so it reaches back to the Research Agent by node name.
  3. Leave the output parser off here - you want readable prose, not JSON.
Prompt (User Message)Expression mode - pulls from two nodes 
Create a comprehensive report on: {{ $('Research Agent').item.json.output.topic }}

Use this research data:
{{ JSON.stringify($('Research Agent').item.json.output, null, 2) }}

And this analysis:
{{ JSON.stringify($json.output, null, 2) }}

Generate a professional business report (500-700 words).
$('Research Agent') must match your node name exactly, including spaces and capitals. If you renamed the node, update the text inside the quotes.
System Message 
You are a professional report writer. Create a well-structured business report using:
- The original research findings
- The analytical insights provided

Format the report with:
1. Executive Summary (2-3 sentences)
2. Key Findings (bullet points)
3. Detailed Analysis (2-3 paragraphs)
4. Recommendations (3-5 actionable items)
5. Sources

Keep the tone professional but accessible.

Use clear headers and formatting.

Troubleshooting

What you see What to do
The model replies about "JSON.stringify" or says it received no data. The field is still on Fixed. Switch it to Expression and check the Result preview shows real JSON.
The Result preview shows undefined. The previous node has not run yet, or it does not produce the field you asked for. Run the earlier nodes once so real data exists, then recheck.
$json.chatInput is empty or undefined in the Research Agent. The node feeding the Research Agent is not a Chat Trigger, or no chat message has been sent yet. Send a message from the chat panel first. Note that only the first agent sees chatInput; later agents see the previous agent's output instead.
The next agent receives a wall of escaped text with \n everywhere. You are stringifying a string instead of an object. Confirm the upstream agent has Require Specific Output Format turned on with a Structured Output Parser attached.
Referenced node doesn't exist in Step 3. The name inside $('Research Agent') does not match the node name. Copy the name from the canvas exactly.
Output is valid JSON but fields are missing. Check that every field you need is listed under "required" in the schema.
