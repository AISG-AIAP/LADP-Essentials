Module 0 - Setup

Following the Demos with n8n

Flowise has been sunset. The hands-on demos in this course can also be done in n8n. This page sets out the facts and the n8n options, so you can choose whichever works for you.

Why This Page Exists

The FlowiseAI team has sunset Flowise, and it reached end of life on 31 August 2026. The timeline was:

Date What happened
29 July 2026 Announcement and code freeze. Feature development stopped and new pull requests were no longer accepted.
10 August 2026 GitHub repository archived. The code remains visible, but issues and pull requests are locked, and npm packages and Docker images are marked deprecated.
31 August 2026 End of life. The core team no longer supports Flowise on Discord or GitHub.

Flowise is Apache 2.0 licensed, so the archived source code is still available to fork. However, it no longer receives fixes or updates.

The course videos demonstrate the hands-on exercises in Flowise, and n8n versions of the demos are also provided. You can use either, or any other framework you prefer. The choice is yours.

The framework does not matter. This course teaches the underlying ideas: prompts, LLM messages, chain-of-thought, prompt chaining, structured output, agents, and tools. These ideas work the same way in any low-code or code-based framework. We have rebuilt the demos in n8n to show that the exact same workflows can be built with a different tool.
Same concept → Same LLM → Same prompts → Different canvas

Ways to Run n8n

If you choose n8n, you can use the hosted version (n8n Cloud) or run it yourself. The hosted version needs nothing installed and runs in your browser, while self-hosting gives you full control on your own machine.

Option Suits you if Cost
A. n8n Cloud free trial You are a new n8n user and do not want to install anything. Free for 2 weeks for new users (at the time of writing)
B. Existing n8n account You already have access to n8n, for example through work or an earlier sign-up. Depends on your existing plan
C. n8n Cloud paid subscription You want to keep using n8n beyond the trial without managing a server. See n8n pricing
D. Self-hosted / local install You are comfortable with Docker or Node.js and want long-term use on your own machine. Free (Community Edition). You still pay for your own LLM API usage.
Whichever option you choose, you still need an LLM API key (for example OpenAI, Anthropic, or Google Gemini). n8n is the canvas, and the model provider is billed separately. See the Provisioning LLM API Credentials section of the Module 0 README.

Option A: Using the 2-Week Free Trial

At the time of writing, n8n offers new users a 2-week free trial of the hosted version. The trial clock starts when you sign up, so plan when you sign up:

  1. Watch the videos first. Go through the course videos without signing up, so you understand each demo before you build it.
  2. Sign up when you are ready to build. Create your n8n Cloud account at n8n.io once you have set aside time for the hands-on work.
  3. Do all the hands-on demos within the 2 weeks. Import the provided workflow files (see below), connect your API key, and run each demo.
  4. Export your work before the trial ends. Download each workflow as JSON so you keep a copy, even if you do not subscribe.
Trial length and plan details are set by n8n and may change. Always check the current offer on the n8n pricing page before you sign up.

Option B: Use an Existing n8n Account

If you already have an n8n account, whether Cloud or self-hosted, just log in and import the course workflows into it. No extra setup is needed.

Option C: Subscribe to n8n Cloud

If you want to continue after the trial, upgrade from inside your n8n Cloud workspace. Compare plans on the pricing page.

Option D: Self-Host or Run n8n Locally

The n8n Community Edition can be run on your own machine for free, using either Docker or npm. Docker avoids having to install and manage a specific Node.js version.

Using Docker

Create a volume and start n8nYour workflows and credentials are saved in the n8n_data volume 
docker volume create n8n_data

docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

Using npm / npx

Try n8n without installingRequires a supported Node.js version - check the n8n docs 
npx n8n
Or install globally and start 
npm install n8n -g
n8n start

Once it is running, open http://localhost:5678 in your browser and create your local owner account.

Importing the Course Workflows into n8n

Every n8n demo in this course comes with a ready-made workflow file, which you will find as a .json file in that module's folder. Importing it gives you the finished workflow so you can compare it with what you build.

  1. In n8n, create a new workflow.
  2. Open the … menu at the top right and choose Import from File, then select the .json file. You can also open the JSON file in a text editor, copy everything, and paste it straight onto the canvas with Ctrl/Cmd+V.
  3. Open each Chat Model node and select or create your own credential. Credentials are never included in exported files.
  4. Click Open chat at the bottom of the canvas and send a message to test it.

Flowise to n8n: What Maps to What

If you are watching a Flowise video and building in n8n, use this table to find the equivalent piece.

In Flowise In n8n
Chatflow / Agentflow Workflow
Chat window / Start node Chat Trigger node (When chat message received)
Agent / LLM node AI Agent node
ChatOpenAI, ChatAnthropic, and other chat models OpenAI Chat Model, Anthropic Chat Model, and so on, attached to the AI Agent's Chat Model input
System message / prompt template System Message option and Prompt (User Message) field on the AI Agent
Buffer Memory Simple Memory node, attached to the AI Agent's Memory input
Structured Output Parser / JSON structured output Structured Output Parser, enabled with Require Specific Output Format
Flow state / variables passed between nodes Expressions such as {{ $json.output }} and {{ $('Node Name').item.json }}
Tools (Calculator, web search, custom tools) Tool nodes attached to the AI Agent's Tool input
Credentials (sidebar) Credentials (Overview page, or created directly from a node)
Load / Export Chatflow (JSON) Import from File / Download (JSON)

Troubleshooting

What you see What to do
Imported workflow shows red warning icons on the Chat Model nodes. Credentials are not included in workflow files. Open each Chat Model node and select or create your own credential.
The model name in an imported workflow is not available. Pick any current model from the dropdown in the Chat Model node. The demo concepts do not depend on a specific model.
Import from File is greyed out or missing. Make sure you are inside a workflow (create a new one first). As an alternative, copy the JSON and paste it onto the canvas.
The trial has ended and I can no longer edit workflows. Subscribe to a Cloud plan, or run n8n locally (Option D) and import the JSON files you exported.
localhost:5678 does not load after running Docker. Check Docker Desktop is running and that nothing else is using port 5678. Look at the terminal output for errors.
Data passed between nodes looks wrong or shows undefined. See the Module 1.3.5 copy-paste guide for how expressions work, including the Fixed vs Expression setting.
